# API «Тайный Санта»

Базовый URL: `http://127.0.0.1:5000`

Все запросы и ответы — JSON (`Content-Type: application/json`).

Единый формат ответа:

```json
// успех
{ "success": true, "data": ..., "message": "..." }

// ошибка
{ "success": false, "error": "Текст ошибки" }
```

Коды ответов:

| Код | Значение |
|-----|----------|
| 200 | Успех |
| 201 | Ресурс создан |
| 400 | Ошибка валидации запроса |
| 403 | Неверный код организатора / результаты скрыты |
| 404 | Комната не найдена |
| 409 | Конфликт (дубль email, повторная жеребьёвка) |
| 500 | Внутренняя ошибка сервера |

## Health-check

### `GET /`

Проверка живости сервера.

**Пример:**

```bash
curl http://127.0.0.1:5000/
```

**Ответ:** `200`

```
Backend is working!
```

## Комнаты

### `POST /api/rooms`

Создание комнаты.

**Параметры тела:**

| Поле | Тип | Обязательное | Описание |
|------|-----|--------------|----------|
| `title` | string | да | Название комнаты (не пустое) |

**Пример:**

```bash
curl -X POST http://127.0.0.1:5000/api/rooms \
  -H "Content-Type: application/json" \
  -d '{"title": "Новый год 2026"}'
```

**Ответ:** `201`

```json
{
  "success": true,
  "data": {
    "id": 1,
    "title": "Новый год 2026",
    "room_code": "K3M9XQ",
    "admin_code": "pX9r2...секретный код..."
  },
  "message": "Комната создана"
}
```

> `admin_code` возвращается **только при создании комнаты**. Это ключ
> организатора к результатам жеребьёвки — его нельзя показывать участникам.
> Через `GET /api/rooms/<id>` этот код не отдаётся.

**Ошибки:**

| Код | Когда |
|-----|-------|
| 400 | `title` отсутствует/пустое |
| 409 | Сгенерированный `room_code` совпал с существующим (повторить запрос) |

---

### `GET /api/rooms/<room_id>`

Информация о комнате по id.

**Пример:**

```bash
curl http://127.0.0.1:5000/api/rooms/1
```

**Ответ:** `200`

```json
{
  "success": true,
  "data": {
    "id": 1,
    "title": "Новый год 2026",
    "room_code": "K3M9XQ",
    "show_results": 0
  }
}
```

> `admin_code` намеренно не возвращается: иначе любой участник смог бы
> увидеть все пары жеребьёвки.

**Ошибки:**

| Код | Когда |
|-----|-------|
| 404 | Комната не найдена |

## Участники

### `POST /api/rooms/<room_id>/users`

Регистрация участника в комнате.

**Параметры тела:**

| Поле | Тип | Обязательное | Описание |
|------|-----|--------------|----------|
| `name` | string | да | Имя участника (не пустое) |
| `email` | string | да | Email (базовая проверка: есть `@` и точка в домене). Один email — один вход в комнату |
| `wish` | string | нет | Пожелание к подарку для Тайного Санты |

**Пример:**

```bash
curl -X POST http://127.0.0.1:5000/api/rooms/1/users \
  -H "Content-Type: application/json" \
  -d '{"name": "Аня", "email": "anya@mail.ru", "wish": "Книга"}'
```

**Ответ:** `201`

```json
{
  "success": true,
  "data": {
    "id": 1,
    "room_id": 1,
    "name": "Аня",
    "email": "anya@mail.ru",
    "wish": "Книга"
  },
  "message": "Участник добавлен"
}
```

**Ошибки:**

| Код | Когда |
|-----|-------|
| 400 | Невалидное имя или email |
| 404 | Комната не найдена |
| 409 | Email уже участвует в этой комнате |

> Один и тот же email может участвовать в разных комнатах.

---

### `GET /api/rooms/<room_id>/users`

Список участников комнаты (в порядке присоединения).

**Пример:**

```bash
curl http://127.0.0.1:5000/api/rooms/1/users
```

**Ответ:** `200`

```json
{
  "success": true,
  "data": [
    { "id": 1, "room_id": 1, "name": "Аня", "email": "anya@mail.ru", "wish": "Книга" },
    { "id": 2, "room_id": 1, "name": "Боря", "email": "borya@mail.ru", "wish": null }
  ]
}
```

**Ошибки:**

| Код | Когда |
|-----|-------|
| 404 | Комната не найдена |

## Жеребьёвка

### `POST /api/rooms/<room_id>/shuffle`

Проведение жеребьёвки. Проводится **один раз** на комнату — повторное
перемешивание запрещено (у каждого участника уже назначен получатель).

Логика: участники перемешиваются случайно и замыкаются в круг —
первый дарит второму, второй третьему, ..., последний дарит первому.
Никто не дарит сам себе.

Пары в ответе **не возвращаются** — они секретны и не выдаются через API.

**Условия:**
- минимум 3 участника (на двух жеребьёвка теряет смысл: пары «друг другу» раскрывают обоих);

**Пример:**

```bash
curl -X POST http://127.0.0.1:5000/api/rooms/1/shuffle
```

**Ответ:** `200`

```json
{
  "success": true,
  "message": "Жеребьёвка проведена",
  "pairs_count": 3
}
```

**Ошибки:**

| Код | Когда |
|-----|-------|
| 400 | Участников меньше трёх |
| 404 | Комната не найдена |
| 409 | Жеребьёвка уже была проведена |

## Результаты для организатора (галочка)

Бизнес-правило из ТЗ: организатор видит **все** пары жеребьёвки только в том
случае, если поставил специальную галочку. Право организатора подтверждается
`admin_code`, полученным при создании комнаты. Остальные участники видят
только свою пару через `POST /api/rooms/<id>/result`.

### `PUT /api/rooms/<room_id>/results/settings`

Поставить или снять галочку «показывать результаты организатору».

**Параметры тела:**

| Поле | Тип | Обязательное | Описание |
|------|-----|--------------|----------|
| `admin_code` | string | да | Секретный код организатора (из ответа создания комнаты) |
| `show_results` | boolean | да | `true` — показывать результаты, `false` — скрыть |

**Пример:**

```bash
curl -X PUT http://127.0.0.1:5000/api/rooms/1/results/settings \
  -H "Content-Type: application/json" \
  -d '{"admin_code": "pX9r2...", "show_results": true}'
```

**Ответ:** `200`

```json
{
  "success": true,
  "data": { "room_id": 1, "show_results": true },
  "message": "Настройки показа результатов обновлены"
}
```

**Ошибки:**

| Код | Когда |
|-----|-------|
| 400 | `admin_code` пустой или `show_results` не boolean |
| 403 | Неверный `admin_code` |
| 404 | Комната не найдена |

---

### `POST /api/rooms/<room_id>/results`

Все пары жеребьёвки (кто дарит → кому дарит) для организатора.
Доступно только при верном `admin_code` **и** установленной галочке.
POST используется, чтобы секретный код не попадал в URL.

**Параметры тела:**

| Поле | Тип | Обязательное | Описание |
|------|-----|--------------|----------|
| `admin_code` | string | да | Секретный код организатора |

**Пример:**

```bash
curl -X POST http://127.0.0.1:5000/api/rooms/1/results \
  -H "Content-Type: application/json" \
  -d '{"admin_code": "pX9r2..."}'
```

**Ответ:** `200`

```json
{
  "success": true,
  "data": [
    { "giver": "Аня", "receiver": "Боря", "wish": "Книга" },
    { "giver": "Боря", "receiver": "Вика", "wish": null }
  ],
  "message": "Результаты жеребьёвки получены"
}
```

**Ошибки:**

| Код | Когда |
|-----|-------|
| 400 | `admin_code` пустой или жеребьёвка ещё не проведена |
| 403 | Неверный `admin_code` или галочка не поставлена |
| 404 | Комната не найдена |

---

## Правила игры (сводка)

1. Организатор создаёт комнату (`POST /api/rooms`).
2. Участники присоединяются по комнате (`POST /api/rooms/<id>/users`), один email — одно участие.
3. После набора участников (минимум 3) организатор проводит жеребьёвку (`POST .../shuffle`).
4. Жеребьёвка необратима: перемешать второй раз нельзя.
5. Пары хранятся в базе и не выдаются через API — участник узнаёт свою пару индивидуально.
6. Организатор видит все пары только по своему `admin_code` и только если поставил галочку
   (`PUT .../results/settings` с `show_results: true`), после чего читает их через `POST .../results`.
