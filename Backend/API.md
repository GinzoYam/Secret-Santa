# API «Тайный Санта»

Базовый URL: `http://127.0.0.1:5000`

Все запросы и ответы — JSON (`Content-Type: application/json`).

Единый формат ответа:

```json
// успех
{ "success": true, "data": ..., "message": "..." }

// ошибка
{ "success": false, "error": "Текст ошибки" }
```

Коды ответов:

| Код | Значение |
|-----|----------|
| 200 | Успех |
| 201 | Ресурс создан |
| 400 | Ошибка валидации запроса |
| 404 | Комната не найдена |
| 409 | Конфликт (дубль email, повторная жеребьёвка) |
| 500 | Внутренняя ошибка сервера |

---

## Health-check

### `GET /`

Проверка живости сервера.

**Пример:**

```bash
curl http://127.0.0.1:5000/
```

**Ответ:** `200`

```
Backend is working!
```

## Комнаты

### `POST /api/rooms`

Создание комнаты.

**Параметры тела:**

| Поле | Тип | Обязательное | Описание |
|------|-----|--------------|----------|
| `title` | string | да | Название комнаты (не пустое) |

**Пример:**

```bash
curl -X POST http://127.0.0.1:5000/api/rooms \
  -H "Content-Type: application/json" \
  -d '{"title": "Новый год 2026"}'
```

**Ответ:** `201`

```json
{
  "success": true,
  "data": {
    "id": 1,
    "title": "Новый год 2026",
    "room_code": "K3M9XQ"
  },
  "message": "Комната создана"
}
```

**Ошибки:**

| Код | Когда |
|-----|-------|
| 400 | `title` отсутствует/пустое |
| 409 | Сгенерированный `room_code` совпал с существующим (повторить запрос) |

---

### `GET /api/rooms/<room_id>`

Информация о комнате по id.

**Пример:**

```bash
curl http://127.0.0.1:5000/api/rooms/1
```

**Ответ:** `200`

```json
{
  "success": true,
  "data": {
    "id": 1,
    "title": "Новый год 2026",
    "room_code": "K3M9XQ",
    "admin_code": null
  }
}
```

**Ошибки:**

| Код | Когда |
|-----|-------|
| 404 | Комната не найдена |

## Участники

### `POST /api/rooms/<room_id>/users`

Регистрация участника в комнате.

**Параметры тела:**

| Поле | Тип | Обязательное | Описание |
|------|-----|--------------|----------|
| `name` | string | да | Имя участника (не пустое) |
| `email` | string | да | Email (базовая проверка: есть `@` и точка в домене). Один email — один вход в комнату |
| `wish` | string | нет | Пожелание к подарку для Тайного Санты |

**Пример:**

```bash
curl -X POST http://127.0.0.1:5000/api/rooms/1/users \
  -H "Content-Type: application/json" \
  -d '{"name": "Аня", "email": "anya@mail.ru", "wish": "Книга"}'
```

**Ответ:** `201`

```json
{
  "success": true,
  "data": {
    "id": 1,
    "room_id": 1,
    "name": "Аня",
    "email": "anya@mail.ru",
    "wish": "Книга"
  },
  "message": "Участник добавлен"
}
```

**Ошибки:**

| Код | Когда |
|-----|-------|
| 400 | Невалидное имя или email |
| 404 | Комната не найдена |
| 409 | Email уже участвует в этой комнате |

> Один и тот же email может участвовать в разных комнатах.

---

### `GET /api/rooms/<room_id>/users`

Список участников комнаты (в порядке присоединения).

**Пример:**

```bash
curl http://127.0.0.1:5000/api/rooms/1/users
```

**Ответ:** `200`

```json
{
  "success": true,
  "data": [
    { "id": 1, "room_id": 1, "name": "Аня", "email": "anya@mail.ru", "wish": "Книга" },
    { "id": 2, "room_id": 1, "name": "Боря", "email": "borya@mail.ru", "wish": null }
  ]
}
```

**Ошибки:**

| Код | Когда |
|-----|-------|
| 404 | Комната не найдена |

## Жеребьёвка

### `POST /api/rooms/<room_id>/shuffle`

Проведение жеребьёвки. Проводится **один раз** на комнату — повторное
перемешивание запрещено (у каждого участника уже назначен получатель).

Логика: участники перемешиваются случайно и замыкаются в круг —
первый дарит второму, второй третьему, ..., последний дарит первому.
Никто не дарит сам себе.

Пары в ответе **не возвращаются** — они секретны и не выдаются через API.

**Условия:**
- минимум 3 участника (на двух жеребьёвка теряет смысл: пары «друг другу» раскрывают обоих);

**Пример:**

```bash
curl -X POST http://127.0.0.1:5000/api/rooms/1/shuffle
```

**Ответ:** `200`

```json
{
  "success": true,
  "message": "Жеребьёвка проведена",
  "pairs_count": 3
}
```

**Ошибки:**

| Код | Когда |
|-----|-------|
| 400 | Участников меньше трёх |
| 404 | Комната не найдена |
| 409 | Жеребьёвка уже была проведена |

---

## Правила игры (сводка)

1. Организатор создаёт комнату (`POST /api/rooms`).
2. Участники присоединяются по комнате (`POST /api/rooms/<id>/users`), один email — одно участие.
3. После набора участников (минимум 3) организатор проводит жеребьёвку (`POST .../shuffle`).
4. Жеребьёвка необратима: перемешать второй раз нельзя.
5. Пары хранятся в базе и не выдаются через API — участник узнаёт свою пару индивидуально.
