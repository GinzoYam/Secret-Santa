🎄 ТАЙНЫЙ САНТА 

Проект демонстрирует связку React (Frontend) и Flask (Backend) с использованием SQLite.
Реализованы: маршрутизация (React Router), создание комнаты (POST), переход на страницу комнаты по ID (useParams), добавление участников (POST), получение списка участников (GET) и отображение через компоненты. Запуск осуществляется в двух терминалах (фронтенд и бэкенд).


ИНСТРУКЦИЯ ПО ЗАПУСКУ 

Перед началом убедитесь, что у вас установлены Node.js и Python.

Проект нужно запускать в ДВУХ терминалах одновременно: один для сервера, второй для сайта.

ТЕРМИНАЛ 1: ЗАПУСК БЭКЕНДА (СЕРВЕР)
1. Откройте VS Code с папкой проекта.
2. В верхнем меню нажмите Terminal -> New Terminal (или нажмите Ctrl + ~).
3. В открывшемся терминале введите команду чтобы перейти в папку с сервером:
   cd Backend
4. Установите необходимые библиотеки Python (это делается только один раз):
   pip install -r requirements.txt
5. Запустите сервер:
   python app.py
   (Оставьте этот терминал открытым. Если всё хорошо, в нём появится сообщение, что сервер работает.)

ТЕРМИНАЛ 2: ЗАПУСК ФРОНТЕНДА (САЙТ)
1. Не закрывая первый терминал, откройте НОВЫЙ терминал (в панели терминала нажмите на значок +).
2. Перейдите в папку с сайтом:
   cd Frontend
3. Установите зависимости Node.js (это делается только один раз):
   npm install
4. Запустите сайт:
   npm run dev
   (В терминале появится ссылка.)

ПРОВЕРКА РАБОТЫ
1. Откройте браузер.
2. Введите в адресную строку: http://localhost:5173/
3. Вы должны увидеть тёмно-зелёную карточку «Тайный Санта» со снежинками.
4. Введите название комнаты и нажмите «Создать». Если вас перекинуло на страницу с адресом /room/1 — всё работает!


ЕСЛИ ЧТО-ТО ПОШЛО НЕ ТАК
- Ошибка "npm не является внутренней..." — не установлен Node.js.
- Ошибка "pip не является..." — не установлен Python (или не добавлен в PATH).
- При создании комнаты пишет «Ошибка соединения» — вы забыли запустить Бэкенд (Терминал 1). Убедитесь, что он всё ещё работает.
- Белый экран в браузере — нажмите F12, откройте вкладку Console и посмотрите на красные ошибки. Скорее всего, вы не выполнили npm install.

ТАК ЖЕ ЕСТЬ АДМИН-СТРАНИЦА
Для перехода на нее введите в адресную строку: http://localhost:5173/superadmin (или допишите вручную /superadmin, если вы находитесь на главной странице)
